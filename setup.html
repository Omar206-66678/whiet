ربط قاعدة البيانات

الطلبات بتوصل لتليفون المالك لما كل الأجهزة تستخدم نفس قاعدة البيانات. الوضع التجريبي بيحفظ على كل جهاز لوحده. اتبعي الخطوات دي مرة واحدة.

1 أنشئي مشروع Supabase

من supabase.com اعملي مشروع جديد مجاني، واحفظي كلمة سر قاعدة البيانات.

2 شغّلي ملف الإعداد

افتحي SQL Editor في Supabase، الصقي المحتوى كله واضغطي Run (مرة واحدة).

فتح الملف

3 البريد ورمز التحقق

  1. Authentication › Providers › Email: فعّلي Confirm email.
  2. فعّلي Custom SMTP بخدمة مجانية (Resend أو Brevo).
  3. عدّلي قوالب الرسائل لتعرض {{ .Token }}.

التفاصيل والقوالب الجاهزة في EMAIL_SETUP.md.

4 اختبار الاتصال

من Project Settings › API انسخي Project URL و anon public key (مش service_role أبدًا).
